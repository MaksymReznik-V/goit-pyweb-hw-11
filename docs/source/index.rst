Contacts REST API Documentation
===============================

Документація REST API застосунку для керування контактами.

Застосунок підтримує:

* реєстрацію та авторизацію користувачів;
* JWT access та refresh tokens;
* підтвердження електронної пошти;
* створення, пошук, редагування та видалення контактів;
* пошук найближчих днів народження;
* завантаження аватара користувача;
* обмеження кількості запитів.
